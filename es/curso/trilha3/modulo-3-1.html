Por qué generar hooks con IA (y la regla de oro)

Ya tienes 165 hooks y la fórmula. La IA entra para multiplicar: generar docenas de variaciones en tu nicho, en segundos. Pero hay una regla de oro: la IA hace el borrador, tú editas y eliges.

🆕 ¿Nuevo por aquí? ¿Qué es un "prompt"?

Un prompt es la instrucción que le das a la IA (ChatGPT, Claude, etc.). Un buen prompt de hook incluye: rol ("eres guionista viral"), contexto (nicho, fórmula), tarea (cuántos hooks, formato) y restricciones (corto, específico, sin clichés).

✓ Prompt contundente

  • ✓Define el rol ("guionista de videos cortos")
  • ✓Da la fórmula y los 5 patrones
  • ✓Exige formato (tabla/CSV) y especificidad
  • ✓Prohíbe explícitamente los clichés

✗ Prompt débil

  • ✗"Dame algunos hooks buenos"
  • ✗Sin fórmula ni patrones
  • ✗Sin formato (la respuesta se convierte en texto suelto)
  • ✗Sin restricciones → el resultado es genérico

⚠️ La IA se excede

Los modelos de IA suelen sonar genéricos («consejos increíbles»). Por eso el prompt PROHÍBE los clichés y exige la fórmula + algo específico. Y aun así: tú filtras. 30 generados y 3 útiles es un excelente resultado.

Prompt 1 — el Generador de Hooks

Copia este prompt en ChatGPT/Claude. Genera 20 hooks de tu nicho siguiendo la fórmula, en formato de tabla con las 3 capas. Cambia lo que está en <colchetes>.

🎯 Objetivo: Generar 20 hooks virales listos para tu nicho, con las 3 capas.
Você é um roteirista de vídeo curto especialista em hooks virais (TikTok, Reels, Shorts).

NICHO: <seu nicho — ex.: finanças pessoais para iniciantes>
IDIOMA: <português do Brasil>

Gere 20 hooks seguindo a fórmula "Context Lean → Scroll Stop → Contrarian Snapback":
- Context Lean: comece no pico, zero "oi pessoal", zero contexto inútil.
- Scroll Stop: a cena/afirmação que trava o dedo nos 3 primeiros segundos.
- Contrarian Snapback: contrarie uma crença comum do nicho ("...não é", "pare de...", "você acha X, mas...").

Use estes 5 padrões, ~4 hooks de cada: medo/alta aposta, contrarian, número/especificidade, prova pessoal, curiosidade/loop aberto.

REGRAS:
- Cada hook em 3 camadas: (1) Frase falada — máx 12 palavras; (2) Visual Hook — a cena na tela; (3) Text Hook — 2 a 3 palavras de overlay.
- Específico vence genérico: use números, valores, prazos.
- PROIBIDO: clichê ("dicas incríveis"), abertura genérica, promessa vaga.

Responda em TABELA com colunas: # | Frase falada | Visual Hook | Text Hook | Padrão.
✅ Cómo verificar: La IA debe devolver una tabla de 20 filas. Revisa: ¿cada frase hablada tiene una brecha (curiosidad) y algo específico? ¿El Text Hook tiene como máximo 3 palabras? Si queda genérico, responde "hazlo más contrarian y específico".

💡 Modelo recomendado

Usa el modelo más capaz disponible (p. ej., Claude Opus o el GPT más reciente). Los hooks dependen de los matices: los modelos pequeños ofrecen más clichés.

Prompt 2 — Generador de las 3 capas a partir de una frase

¿Ya tienes una buena frase, pero te faltan el elemento visual y el texto en pantalla? Este prompt completa las 3 capas de cualquier línea que le des.

🎯 Objetivo: Convertir una frase hablada suelta en las 3 capas completas (con 3 opciones visuales).
Tenho esta frase falada de hook: "<cole sua frase aqui>".

Complete as 3 camadas:
1) Refine a frase falada (máx 12 palavras, mantendo a ideia, mais punchy).
2) Proponha 3 opções de Visual Hook — cenas concretas e legíveis em tela de celular, com tensão ou contraste. Descreva cada cena em 1 linha.
3) Proponha 3 opções de Text Hook (2 a 3 palavras cada).

Para cada Visual Hook, diga em 1 frase POR QUE ele para o dedo.
Formato: listas curtas, sem enrolação.
✅ Cómo verificar: Debes recibir 1 frase refinada + 3 visuales + 3 textos. Elige 1 de cada uno. Prueba mental: ¿el visual elegido funciona sin sonido? ¿El texto se entiende de un vistazo?
▸ Profundicemos: cómo pedir variaciones sin repetir

Después de la primera tanda, pide: "Ahora dame 5 versiones más atrevidas y 5 más sobrias de la misma frase, sin repetir los verbos iniciales." Restringir lo que NO se debe repetir (verbos, estructura) obliga a la IA a explorar nuevos ángulos en vez de variar solo las palabras.

Prompt 3 — generar el prompt de IMAGEN del Visual Hook

El Visual Hook se convierte en una imagen. Este prompt produce un prompt de imagen listo para pegar en un generador (flux2-klein, Midjourney, etc.), exactamente como se hicieron las 165 imágenes de este curso.

🆕 ¿Nuevo por aquí? Por qué un prompt genera otro prompt

Los generadores de imágenes tienen un «lenguaje» propio (estilo, luz, lente, negativos). Pedirle a la IA que traduzca tu Visual Hook a ese lenguaje ahorra prueba y error y mantiene un estilo visual coherente.

🎯 Objetivo: Convertir un Visual Hook en un prompt de imagen cinematográfico listo para copiar y pegar.
Converta este Visual Hook num prompt de imagem para um gerador (flux/Midjourney):
VISUAL HOOK: "<ex.: cadeira de escritório vazia, tela com aviso 'Posição Encerrada'>"

Saída: um único parágrafo em inglês, estilo:
"cinematic dark premium thumbnail, <cena>, dramatic moody lighting, deep navy-black background, high contrast, shallow depth of field, photographic realism, volumetric glow, 8k, no text, no watermark"

Mantenha "no text, no watermark" no fim. Não invente texto na imagem (geradores erram letras).
✅ Cómo verificar: La respuesta es 1 párrafo en inglés que termina en "no text, no watermark". Pégalo en el generador. Si aparece texto distorsionado en la imagen, vuelve a generarla con otra seed: "no text" lo reduce, pero no lo elimina por completo.

💡 Servidor local de INEMA

En este curso, las imágenes se crearon con inemaimg (flux2-klein local). El mismo prompt funciona en cualquier generador: la estructura es portátil.

Prompt 4 — lote: 33 hooks de un nicho a la vez

Para reproducir el material original (33 hooks por nicho) en un tema nuevo, pide el lote completo, ya agrupado por patrón.

🎯 Objetivo: Generar un paquete de 33 hooks de un nicho, agrupados según los 5 patrones, en CSV.
Gere 33 hooks virais para o nicho "<seu nicho>", idioma <pt-BR>, seguindo a fórmula Context Lean → Scroll Stop → Contrarian Snapback.

Distribua entre os 5 padrões (medo, contrarian, número, prova pessoal, curiosidade).
Cada hook: frase falada (máx 12 palavras), Visual Hook, Text Hook (2-3 palavras), padrão.

Saída em CSV com cabeçalho:
n,frase_falada,visual_hook,text_hook,padrao

Sem texto fora do CSV. Aspas duplas em campos com vírgula.
✅ Cómo verificar: Guarda la salida como .csv y ábrela en una hoja de cálculo: debe tener 33 filas + encabezado y representar 5 patrones. Filtra las filas débiles; ¿quedaron 20+ buenas? Excelente lote.

Filtrar e iterar: la rúbrica de 5 puntos

Generar es fácil; elegir es el trabajo. Usa esta rúbrica para calificar y quedarte solo con los hooks que merecen convertirse en video.

🧠 Rúbrica: asigna 0 o 1 a cada punto (descarta si queda por debajo de 4/5)

null

  • •¿Específico? tiene un número/valor/plazo concreto.
  • •¿Brecha de curiosidad? deja una pregunta en el aire.
  • •¿Contrarian? contradice una creencia del nicho.
  • •¿Visual? la escena se entiende en 1 segundo, sin sonido.
  • •¿Corto? frase en ~2s, texto de 2-3 palabras.
🎯 Objetivo: Hacer que la IA puntúe y reescriba automáticamente los hooks débiles.
Avalie cada hook da lista abaixo com a rubrica (0 ou 1 cada): específico, lacuna, contrarian, visual, curto. Some (0 a 5).

Para hooks com nota < 4, reescreva uma versão melhor mantendo o tema.
Devolva: tabela com hook | nota | versão melhorada (quando aplicável).

LISTA:
<cole aqui os hooks gerados>
✅ Cómo verificar: Recibes notas + versiones mejoradas. Lleva al siguiente módulo (3.2) solo las que tengan nota 4-5: se convertirán en tu banco de hooks.
