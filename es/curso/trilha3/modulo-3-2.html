De prompt aislado a sistema (tu Hook Machine)

Un prompt individual resuelve un video. Una skill (sistema reutilizable) resuelve los próximos 100: tú le das el nicho y te devuelve hooks + capas + prompts de imagen, siempre con el mismo formato.

🆕 ¿Nuevo por aquí? ¿Qué es una "skill"?

En Claude Code (y herramientas similares), una skill es una carpeta con un archivo SKILL.md que describe CUÁNDO usarla y QUÉ hacer. La invocas con un comando y ejecuta todo el proceso, como tener a un guionista de guardia con su método integrado.

🧠 Qué ofrece tu Hook Machine

null

  • •Recibe: un nicho/tema y el idioma.
  • •Genera: 20-33 hooks con la fórmula, agrupados por patrón.
  • •Completa: las 3 capas de cada hook.
  • •Produce: el prompt de imagen de cada Visual Hook.
  • •Filtra: puntúa con la rúbrica y descarta los débiles.

2

Anatomía de una SKILL.md

Una skill es simple: un encabezado que dice CUÁNDO activarla y un cuerpo que dice CÓMO actuar. Veamos las partes antes de pegar la tuya.

🧠 Las partes de una SKILL.md

null

  • •name: nombre corto de la skill (ej.: hook-machine).
  • •description: cuándo usarla: los desencadenantes ("crear hooks", "generar ganchos virales").
  • •Cuerpo (instrucciones): el paso a paso que sigue la IA: rol, fórmula, formato de salida, rúbrica.

💡 Regla para una buena descripción

La description es lo que hace que la skill se "active" en el momento adecuado. Enumera desencadenantes reales que dirías: "genera hooks para…", "ganchos virales de…", "ideas de Reels sobre…".

# Hook Machine

Você é roteirista de vídeo curto especialista em hooks virais.

## Quando o usuário der um NICHO/ASSUNTO e (opcional) idioma:

1. Gere 20 hooks (ou a quantidade pedida) na fórmula:
   - Context Lean: começa no pico, zero contexto inútil.
   - Scroll Stop: a cena/afirmação que trava o dedo nos 3s.
   - Contrarian Snapback: contraria uma crença comum do nicho.
2. Distribua entre os 5 padrões: medo, contrarian, número, prova pessoal, curiosidade.
3. Para cada hook entregue as 3 CAMADAS:
   - Frase falada (máx 12 palavras)
   - Visual Hook (cena concreta, legível no mudo)
   - Text Hook (2-3 palavras)
4. Pontue cada hook com a rubrica (0/1): específico, lacuna, contrarian, visual, curto. Mostre só os com nota >= 4.
5. Para os aprovados, gere o PROMPT DE IMAGEM (inglês, cinematográfico, terminando em "no text, no watermark").

## Regras
- Específico vence genérico (números, valores, prazos).
- PROIBIDO clichê, abertura genérica, promessa vaga.
- Saída final em tabela: # | Frase falada | Visual Hook | Text Hook | Padrão | Nota | Prompt de imagem.

## Idioma
Responda no idioma pedido (default: português do Brasil).
✅ Cómo verificar: En Claude Code: guarda en hook-machine/SKILL.md y pide «genera hooks de ". En otro chat: pega el cuerpo como primer mensaje y envía el nicho. Debe aparecer la tabla con la puntuación y el prompt de imagen.
4

Pipeline por lotes: del nicho al paquete listo

Con la skill en su lugar, puedes ejecutarla en lote: varios nichos, varios hooks, imágenes incluidas. Aquí tienes el paso a paso reproducible.

🧠 El pipeline, paso a paso

null

  • •1. Generar: ejecuta Hook Machine para el nicho → tabla de hooks aprobados.
  • •2. Imágenes: toma la columna "prompt de imagen" y genera cada una en flux/Midjourney.
  • •3. Armar: combina frase + visual + texto + imagen en una tarjeta (como las de la Ruta 2).
  • •4. Programar: distribuye los hooks en videos a lo largo de la semana.
🎯 Objetivo: Generar todas las imágenes de un lote a partir de una hoja de cálculo de prompts (Node + servidor local).
// salve como gen.js — lê prompts.json [{n, prompt}] e salva PNGs
const http=require('http'),fs=require('fs');
const items=JSON.parse(fs.readFileSync('prompts.json','utf8'));
(async()=>{ for(const it of items){
  const payload=JSON.stringify({model:'flux2-klein',prompt:it.prompt,width:1024,height:576,steps:4,guidance_scale:1.0,seed:it.n});
  const png=await new Promise((ok,no)=>{const r=http.request({host:'localhost',port:8000,path:'/generate',method:'POST',headers:{'Content-Type':'application/json','Content-Length':Buffer.byteLength(payload)}},res=>{let b='';res.on('data',c=>b+=c);res.on('end',()=>ok(Buffer.from(JSON.parse(b).image,'base64')))});r.on('error',no);r.write(payload);r.end();});
  fs.writeFileSync('hook-'+it.n+'.png',png); console.log('ok',it.n);
}})();
✅ Cómo verificar: Ten inemaimg funcionando en localhost:8000. Ejecuta "node gen.js": debe crear hook-1.png, hook-2.png… Cuenta los archivos: deben ser == al número de prompts.
▸ Profundicemos: este curso se hizo así

Las 165 imágenes de la Trilha 2 salieron de un script casi idéntico a este: leyó un JSON con los 165 Visual Hooks, generó cada PNG en inemaimg (flux2-klein, 4 pasos) y lo comprimió a WebP (~23 KB cada uno). El mismo pipeline genera tu paquete.

5

Banco de hooks: reutilizar, etiquetar, versionar

Un buen hook no es desechable. Guarda los aprobados en una base de datos — una hoja de cálculo o JSON — para reutilizarlos, combinarlos y ver qué se repite entre los que tienen éxito.

🧠 Estructura mínima de la base de datos

null

  • •id, nicho, patrón — para filtrar después.
  • •3 capas — frase, visual, texto.
  • •estado — idea / grabado / publicado.
  • •rendimiento — visualizaciones/retención cuando publiques.
🎯 Objetivo: Estandarizar una entrada de tu banco de hooks (JSON reutilizable).
{
  "id": "fin-001",
  "nicho": "financas",
  "padrao": "numero",
  "frase_falada": "Transformei US$500 em US$15.000 sem tocar na bolsa.",
  "visual_hook": "nota de 500 se multiplicando em maços de dinheiro",
  "text_hook": "No Stocks",
  "status": "ideia",
  "views": null
}
✅ Cómo verificar: Crea banco.json como una lista de esos objetos. Para reutilizarlo: filtra por "padrao" o "nicho" y adapta. Cuando publiques, completa "views" y mira qué patrón te funciona mejor.

💡 Versionar con Git

Guarda el banco.json en un repositorio (aprendes esto en el curso "Do Zero ao Deploy" de INEMA). Cada video publicado se convierte en un commit: un historial de lo que funcionó.

6

Publicar y medir: el ciclo que te hace mejorar

El hook solo demuestra su valor en la práctica. Cierra el ciclo: prueba, mide y duplica lo que funciona. Así pasas de "copiar hooks" a "tener un método".

🧠 El ciclo de mejora

null

  • •Prueba: graba 2-3 versiones del mismo contenido con hooks diferentes.
  • •Mide: mira la retención en los 3s y el % que pasó del 50% — no solo las views.
  • •Aprende: ¿qué PATRÓN retuvo más? (¿miedo? ¿número?)
  • •Duplica: repite el patrón ganador en tu nicho.

Me gusta% que superó el 50% del video

⚠️ No confíes en 1 video

Un hook puede volverse viral por suerte y otro morir por el horario. Observa el promedio de 5-10 videos por patrón antes de concluir qué funciona para ti.
